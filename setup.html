⚠️ Important: This setup wizard guides you through the manual setup process. Run it on your server where PHP and MySQL are available.

Step 1: Configure Database

Edit the file myphp-db.php with your actual database credentials:

<?php
return [
    'host' => 'your-db-host.com',
    'port' => 3306,
    'database' => 'your_database_name',
    'username' => 'your_db_user',
    'password' => 'your_db_password',
    'charset' => 'utf8mb4',
];

Step 2: Run Database Migration

Upload all files to your server and run the migration script via browser:

https://your-domain.com/migrate.php

Or via command line (SSH):

php migrate.php
✅ This will create tables and insert default admin account

Step 3: Default Admin Account

After running migration, use these credentials:

Email: admin@azmeer.com
